# Ultimate Scaler - 实验性预览版

> 此版本与主分支开发完全独立，是为快速验证最新快照版地形生成器变化而生的临时工具。

---

## 简介

这是 Ultimate Scaler 的一个实验性预览分支，专门针对 Minecraft 26.3-snapshot-10 的密度函数系统改动而生。

由于开发周期极短，代码质量较为粗糙，可维护性较低。此版本**不会**接入原项目的每日构建体系，**不会**发布到任何第三方模组平台（CurseForge / Modrinth 等）。一旦主分支适配到当前快照版本，此预览版将停止更新。

## 安装与配置

此模组完全由配置文件驱动。由于当前快照版本尚无可用的配置界面模组，你需要手动编辑配置文件。

1. 启动游戏一次，模组会在 `./config/` 目录下生成 `us-preview.toml`
2. 关闭游戏，编辑该文件
3. 保存后重新启动游戏，或在游戏内执行 `/reload` 使配置生效

## 配置项列表

### 坐标重定位

| 配置项                         | 类型           | 说明                                                                                                                                           |
|--------------------------------|----------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `shiftX` / `shiftY` / `shiftZ` | 双精度或字符串 | 世界生成坐标在各个轴上的平移量（单位：方块）。如需高精度运算，请用**字符串**形式传入（如 `"123456789.123456789"`），否则会被解析为双精度浮点数 |
| `scaleX` / `scaleY` / `scaleZ` | 双精度或字符串 | 世界生成坐标在各个轴上的缩放系数。遵循**先平移，再以世界原点为中心缩放**的顺序。同样支持字符串形式传入高精度数值                               |

重定位系统当前影响范围：**所有噪声调用（密度函数、材料规则、雕刻器、地物噪声等）**。

### 行为开关

| 配置项          | 类型 | 说明                                                                                                                                                                                                                             |
|:----------------|:-----|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `forceFarlands` | 布尔 | 禁用高版本坐标折叠算法，将边境之地还原至 32 位坐标（`false` = 原版默认行为），此选项的生效无视调试属性 `MC_ENABLE_FARLANDS`                                                                                                      |
| `oldWrap`       | 布尔 | 将坐标折叠算法还原至 26.3-pre-1 前的实现，使得边境之地可以在极远处生成（64位坐标）。                                                                                                                                             |
| `unsmooth`      | 布尔 | 将柏林噪声的平滑插值公式 `6x⁵-15x⁴+10x³` 替换为 `x`，使地形粗糙化，但可让边境之地在 float 精度下存活更久                                                                                                                         |
| scattered       | 布尔 | 复原早期 MC 的批量噪声采样行为。将元胞内相对坐标从折叠中解放出来，使以下两类现象重新出现：① 极远处的地形以区块为单位高度重复；② 平面比例极高时产生“区块边境之地”（每个区块生成几乎相同的故障高海拔混乱地形）。不影响常规地形生成 |
| `highPrecision` | 布尔 | 使用高精度数学计算重定位坐标（同原版 US），可精准偏移地形并解锁某些整数生成器的重定位，但会拖慢运算速度、增加内存占用。**启用时请确保 shift/scale 值已用字符串形式传入**                                                         |

> 关于 `scattered` 配置项：批量采样是早期 MC 使用的噪声采样方式——上层先划定一个元胞区域，底层对该区域内所有方块按顺序连续采样并批量返回。1.14 重写时被移除，最近快照重新加入并改为全 float。
> 
> 旧版中，上层坐标经过了折叠，但元胞内相对坐标没有，因此当平面比例足够高时，相对坐标×比例会发生整数溢出，产生以区块为单位的重复地形（即“区块边境之地”）。
> 
> `scattered` 所做的，是在新版中复原这个行为：将元胞内相对坐标从折叠中解放出来，使上述现象重新出现。
> 
> 不过，当模组的 scale 类配置项数值较大时，也能和 `scattered` 作用并产生区块边境之地。这是本模组的一个已知漏洞，但我们目前没有找到好的解决方案。

### 混合噪声比例

| 配置项    | 类型   | 默认值    | 说明                                                                                                              |
|-----------|--------|-----------|-------------------------------------------------------------------------------------------------------------------|
| `xzScale` | 双精度 | `684.412` | 混合噪声的平面坐标比例因数。调高可使边境之地在更近的位置生成。**修改后需重启世界才能生效**，仅执行 `/reload` 不够 |
| `yScale`  | 双精度 | `684.412` | 混合噪声的高度比例因数。工作方式同上。**修改后需重启世界**                                                        |
